L159: QCEW provides a collection of CSV files representing logical slices of data. Data are sliced by industry, by area, and by establishment size-class. An industry slice contains all the records associated with the industry for a single time period. An area slice contains all the records associated with the area for a single time period. A size slice contains all records published within a specific size class for the first quarter of a specified year. These three types of slices are detailed below.
L160: These data slices are stored as CSV files. (Comma Separated Values) This file layout is defined below.

L171: ## Data Slices by Industry
L172: An industry slice contains all the records associated with the industry for a single time period. Industry slices are stored in folders by year and quarter. Consider the following URL:
L173:     cite150†https://data.bls.gov/cew/data/api/2026/1/industry/10.csv†data.bls.gov L174: This URL points to the total, all industries (NAICS 10) CSV file for first quarter 2026. Notice the year, quarter, and industry codes (2026,1, and 10) are all visible in the URL. You can change these values to point at different time periods and industries. The URL above also contains the word "industry". This designates the type of data you're requesting. In this case we're requesting industry data. Some NAICS codes are hyphenated. For example, the NAICS code for manufacturing is 31-33.
L175: Industry file names do not contain hyphens, only numbers and underscores. So, the file for manufacturing is actually "31_33.csv" and to request first quarter manufacturing data for 2026, you'd use the following URL: cite151†https://data.bls.gov/cew/data/api/2026/1/industry/31_33.csv†data.bls.gov . For a complete list of industry titles and codes see the cite152†QCEW Industry Titles page.
L176: ## Data Slices by Area
L177: An area slice contains all the records associated with the area for a single time period. Area slices are stored in folders by year and quarter. Consider the following URL:
L178:     cite153†https://data.bls.gov/cew/data/api/2026/1/area/26000.csv†data.bls.gov L179: This URL points to the Michigan, State-level CSV file for first quarter 2026. Notice the year, quarter, and area code (2026,1, and 26000) are all visible in the URL. You can change these values to point at different time periods and areas. The URL above also contains the word "area". This designates the type of data you're requesting. In this case we're requesting area data. For a complete list of area titles and codes see the cite154†QCEW Area Titles page.
L180: ## Data Slices by Size Class
L181: A size slice contains all records published within a specific size class for the first quarter of a specified year. Consider the following URL:
L182:     cite155†https://data.bls.gov/cew/data/api/2026/1/size/3.csv†data.bls.gov L183: This URL points to the size-class 3 CSV file for first quarter 2026. Notice the year, quarter, and size code (2026,1, and 3) are all visible in the URL. You can change these values to point at different time periods and size classes. Note that size data is only available for the first quarter of each year. The URL above also contains the word "size". This designates the type of data you're requesting. In this case we're requesting size data. For a complete list of size-class titles and codes see the
L184: cite156†QCEW Size Titles page.
L185: Note: Data slices by size class do not include data for "All Establishment Sizes" (Size code=0). Please use the data slices by area or industry for these concepts.
